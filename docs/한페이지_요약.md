# 16조 스타벅스 – 한 페이지 요약

## 문제

- Starbucks Capstone 데이터는 `channels`, `value` 등이 **문자열**로 저장되어 있어 그대로는 집계·조인 불가.
- 고객별 프로모션 반응·채널 성과를 보려면 **구조화 + 조인**이 선행되어야 함.

## 접근

1. **전처리**: `ast.literal_eval` 등으로 channels → channel_email·channel_mobile·channel_social·channel_web 플래그, value → offer_id·amount 추출.
2. **조인**: Profile(customer_id) ↔ Transcript(person), Transcript(offer_id) ↔ Portfolio(id).
3. **시각화**: 조인 결과를 Tableau에 올려 KPI·세그먼트별 반응률·채널별 성과 대시보드 제작.

## 결과

- **starbucks_merged.csv**: 한 테이블에서 “누가, 어떤 오퍼를, 언제, 어떻게 반응했는지” 분석 가능.
- **스벅_최종_통합본.twb**: 이해관계자 전달용 대시보드.

## 한계

- 데이터 기간·지역 제한.
- Tableau 없이도 결과를 보려면 스크린샷 또는 대체 시각화(Matplotlib/Streamlit 등) 추가 권장.

## 기술 스택

- Python (pandas, numpy), Jupyter, Tableau.
